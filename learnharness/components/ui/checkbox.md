# Checkbox

One of several independent choices: a multi-select question's options, Delete session's traces. `checkbox.tsx`, shadcn's Radix checkbox; `data-slot` `checkbox`, `checkbox-indicator`. `checked="indeterminate"` draws a dash.

| State | Look |
|---|---|
| clear | 16px, radius 4, 1px inset `muted-foreground` ring |
| checked | `primary` fill, white 12px check (stroke 3) |
| indeterminate | `primary` fill, white dash |
| focus | 2px `ring`, offset 2 |
| disabled | 50% |

Sources: shadcn checkbox, the question dock's drawn markers it replaces (one accent for chosen controls).
