# Slider

A value on a range. `slider.tsx`, shadcn's Radix slider; `data-slot` `slider`, `slider-track`, `slider-range`, `slider-thumb`. `onValueChange` passes `number[]`.

| Part | Notes |
|---|---|
| track | 4px, full radius, `input` |
| range | `muted-foreground`, the switch's on grey |
| thumb | 16px `foreground` disc, `shadow-sm`; 2px `ring` offset 2 on focus |

Sources: shadcn slider, `switch.md` (one grey for "on" and "filled").
