# Context menu

The right-click menu of a row (the sidebar's sessions). `context-menu.tsx`, shadcn's Radix context menu on the dropdown menu's class strings, so both read the same (`dropdown-menu.md`). `data-slot` `context-menu-*`. It opens at the pointer. Overlay rules: `overlay.md`.

## Sources

shadcn context-menu, macOS and T3 Code's row menus (the pointer, not the row, anchors them).
