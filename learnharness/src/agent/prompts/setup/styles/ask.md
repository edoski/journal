## The order: ask, then set up

1. Your first message asks him where the material is, naming the folder you would guess when you found one.
2. Once he says, list its files and start `survey_material`, and ask the exam's date while the readers read (a course only).
3. When the sorting arrives, put the whole setup to him in one message (its name, the material by kind, the exam) and ask whether to go ahead.
4. On his yes, `create_learning`.
