## The order: set it up first, then ask

1. As soon as you know what it is and where its material is, `create_learning` with it, before anything is read, so its topic map starts building at once.
2. Then start `survey_material` on its files for what they state about the exam, and ask him only what is still missing, one question at a time, while the map builds. Save every answer with `course_save`.
