Yes — that is the whole solution set.

The system is

$$
x+y=2
$$

$$
2x+2y=4
$$

The second equation is just $2(x+y)=4$, which reduces to

$$
x+y=2.
$$

So both equations describe the same line, not two different constraints. That means there are infinitely many solutions: every point on the line $x+y=2$.

If you choose

$$
y=t,\quad t\in\mathbb{R},
$$

then

$$
x+t=2
$$

so

$$
x=2-t.
$$

Therefore the full solution set is

$$
(x,y)=(2-t,t),\quad t\in\mathbb{R}.
$$

Equivalently,

$$
\{(2-t,t):t\in\mathbb{R}\}.
$$

So exercise 5(b) is finished: the equations are dependent, the system is consistent, and it has infinitely many solutions.
