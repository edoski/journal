Yes — that is the whole solution set.

The system is

$$
x+y=2
$$

$$
2x+2y=4
$$

The second equation is just twice the first, so it gives no new restriction. Therefore every solution only needs to satisfy

$$
x+y=2.
$$

If you choose

$$
y=t,\quad t\in\mathbb{R},
$$

then

$$
x=2-y=2-t.
$$

So the complete solution set is

$$
(x,y)=(2-t,t),\quad t\in\mathbb{R}.
$$

Equivalently, this is the whole line $x+y=2$. Exercise 5(b) is finished: the system is consistent, dependent, and has infinitely many solutions.
