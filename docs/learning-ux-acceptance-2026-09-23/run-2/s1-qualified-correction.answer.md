What changes is the **working convention**, not the underlying derivations.

- Treat the current lab as **discrete time**: signals like $x[n]$, impulse response $g[n]$, sums rather than integrals.
- The old lab sheets are now only historical/background for this point: if they write $g(t)$ or use continuous-time assumptions, don’t copy that convention into the current lab.
- Use **Lumen** when deciding current notation and lab assumptions.
- Use **Atlas** for derivations, but translate them into the lab’s discrete-time notation when needed.

So a continuous-time relation such as convolution with $g(t)$ should be mentally mapped to the discrete-time version with $g[n]$ and summation, not treated as the lab’s current convention.
