For the current lab, use **discrete-time** notation and Lumen’s conventions: index signals by $n$ and write the impulse response as $g[n]$. Continuous-time expressions such as $g(t)$ belong to the different convention, so don’t carry them into this lab unchanged. Atlas can still help with derivations, but translate the result into the current notation.

Your lecturer’s clarification changes which convention to use; it doesn’t establish which undated sheet is an older edition.
