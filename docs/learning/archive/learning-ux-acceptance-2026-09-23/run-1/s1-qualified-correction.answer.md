What changes is mainly the **time-domain convention and notation**:

- Treat the **current lab as discrete time**, so signals use brackets: $x[n]$, and the impulse response is $g[n]$.
- The **old lab sheets are continuous time**, so their notation $x(t)$ and $g(t)$ should not be copied as current lab convention.
- Use **Lumen** as the authority for current conventions.
- Use **Atlas** for derivations, but translate notation if needed, especially if Atlas writes the impulse response as $h$ rather than the lecturer’s $g$.

So a continuous-time formula from an old sheet like

$$
y(t) = x(t) * g(t)
$$

should be read for the idea, but rewritten for the current lab as

$$
y[n] = x[n] * g[n].
$$

I won’t treat this as evidence that you’ve learned the mathematics; it’s a source/convention correction.
