Worksheet A exercise 5(b) was:

$$x+y=2,\qquad 2x+2y=4.$$

We established that the second equation is just twice the first, so they describe the same line, not two independent constraints. Therefore there are infinitely many solutions. With $y=t$, the solution set is

$$x=2-t,\qquad y=t,\qquad t\in\mathbb R.$$
