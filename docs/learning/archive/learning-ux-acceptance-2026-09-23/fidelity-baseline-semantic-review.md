Reviewed all 15 completed sessions in `fidelity-sol-baseline`: five fresh repetitions each of qualified correction, new authority, and course recall. Each retained environment identifies baseline `6238921153bb67d7b861bb9a6c688bfd2c2e9555`, Pi `0.87.1`, provider `openai-codex`, model `gpt-6-sol`, and thinking `high`; every recorded model round agrees. All processes completed without reported tool errors or production-source drift.

Judgment uses the frozen [fidelity rubric](evaluator-expectations.md#fidelity-follow-up-rubric-frozen-before-comparison) and [follow-up spec](../learning-fidelity-followup-spec-2026-09-23.md). I read every public answer, every changed value in each complete initial/final state diff, and the public tool-call sequences. Exact comparisons checked untouched evidence and tasks, not merely retained keywords. This is an evaluation of these baseline samples; it is not a candidate comparison or a population reliability claim.

Canonical skill/reference reads are not treated as gratuitous rereads.

## Operational findings and scope of the verdict

The conservative avoidable-file-read count is 14: the 13 recall reads plus the unrelated hostile worksheet in correction repetition 4. A further 13 discovery calls are avoidable: five correction inventories, five searches for the explicitly named authority notice, and three recall inventories. These judgments use the information already present in the prompt or canonical context; they do not count initial skill loading, scope-catalog discovery when only a display name was known, relevant conflicting-source inspection, or the authority notice itself as unnecessary. There are no repeated reads of the same file within a case, no repair retries, and no tool failures.

No sample shows qualification loss, an invented observation, changed assistance, unsolicited internal classification, an unsupported current-source identity, or a new privilege for calculators. Two answers acknowledge the inference restriction after their main explanation. One authority save duplicates a supported fact, one recall save stores an additional supported fact, and several cases retrieve more than the learner's request requires. These findings remain visible alongside the content and saved-meaning passes.

This review does not evaluate the independent candidate batch or controls, actual terminal/Obsidian rendering, implicit skill activation, other providers, delayed learning, or unseen model failures. Five content/meaning successes per profile are the observed baseline outcome for these fixed prompts and settings, with the two placement deviations separately disclosed; they are not proof that previous failure modes cannot recur. Per-round usage and timing remain in each case's metrics artifact; they are not evidence of semantic correctness or one context-window size.
