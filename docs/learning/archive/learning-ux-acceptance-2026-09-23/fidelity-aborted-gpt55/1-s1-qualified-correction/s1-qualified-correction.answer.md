What changes:

- Treat the current lab as **discrete time**, so signals are indexed like $x[n]$, and the impulse response is $g[n]$.
- Do **not** use the old lab sheets as the current convention; they assume **continuous time**, with forms like $x(t)$ and $g(t)$.
- Use **Lumen** for current notation and lab assumptions.
- Use **Atlas** mainly for derivations, but translate its notation/conventions if they differ from Lumen or the lab.

So a formula that appears in a continuous-time old sheet may still express a related idea, but before using it in the current lab you should convert the convention: sums instead of integrals, $n$ instead of $t$, and $g[n]$ rather than $g(t)$.
