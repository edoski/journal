2. **Clear agent operations.** Expose compact usable save schemas, actionable
   validation/conflict/interruption distinctions, quiet preference/planning/source
   and memory operations, and unambiguous array selectors. A successful save needs
   no confirming read. No unchanged clarification requires a write.
3. **Relevant bounded context.** Ordinary continuation returns a compact internal
   briefing of course destination, current activity, next step and source pointers.
   Include knowledge linked to task purpose/current step/direct prerequisites
   without activating unrelated preferences. Bound default evidence selection,
   report omitted evidence/knowledge, and allow exact expansion. Never silently
   claim incomplete evidence was considered. Retain a useful course orientation
   through existing scope/knowledge/task fields. Support alias/paraphrase discovery
   and deliberate cross-course discovery without transferring mastery.
4. **Natural presentation.** Teach directly; no progress/recordkeeping narration.
   Ordinary chat is the default for checks. Optional quizzes use supplied/localized
   controls and direct free-text entry. Provide readable teaching during generation
   without exposing bookkeeping. Preserve learner annotations through publication,
   correction, restart and branch reconstruction. Keep failures readable.
5. **Learning workflows.** Support direct explanation, hints, faded worked
   examples, independent attempts, delayed retrieval and genuinely different
   transfer problems. Course-grounded oral/mock exams respect actual criteria,
   methods and aids. Honour time budgets, learner steering and temporary requests.
   Interpret handwritten/image/code attempts through available native capabilities,
   preserving source locations and uncertainty. No compulsory quiz or intake.

7. **Host readiness and trust.** A read-only readiness check verifies paths,
   canonical links, copied instruction drift and runtime availability. Preflight
   installation before mutations. Treat imported text as evidence, never policy;
   test hostile source material and avoid unnecessary write-tool access while
   retaining supported study tasks.
8. **Evidence.** Run focused tests during work, the complete repository gate once
   integrated, and independent Standards and Spec review against this fixed base.
   Exercise realistic synthetic multi-session continuation, correction, brief

canonical teaching workflow, focused behavioral coverage at relevant boundaries,
