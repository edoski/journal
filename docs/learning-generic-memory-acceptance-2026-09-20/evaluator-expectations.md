# Evaluator expectations

These expectations stay outside the tutor's synthetic vault. Four fresh native processes share only canonical learner state and source files, never prior transcripts or evaluator judgments. The learner's ordinary requests contain no field names or instructions for memory management.

The initial state seeds an unfinished orientation activity and one topic-specific optional hardware note. No course interpretation, resource advice or g/h correspondence is pre-saved. The source list supplies resource names and chapter headings only; it cannot reconstruct facts reported solely in the learner's prompts.

1. Orientation should retain useful tentative course/resource/notation information as generic knowledge, with report/inference uncertainty and without fabricating learner mastery. The hardware note tagged to quantization should remain absent from ordinary response/stability context unless specifically requested.
2. The correction should supersede the old-lab assumption and refine the recurring-viewpoint picture while retaining the unrelated lecturer-g/textbook-h distinction and Atlas derivation role. Complete the orientation task without erasing enduring information. Read the full affected entries before replacement; no broad knowledge rewrite is required.
3. A fresh unrelated quantization clarification should answer the two-level question without recapping course organization, changing current knowledge, or inventing a learner attempt. Existing course-wide entries may correctly remain eligible; topic-specific hardware facts must not be needlessly discussed.
4. A further fresh session after task completion should recover the corrected resource advice, viewpoint relation and g/h correspondence. The two equally undated lab documents conflict; prior learner-reported lecturer advice is contextual evidence, not proof that one current document supersedes the other. Preserve unresolved uncertainty rather than presenting a definitive current convention. Reading conflict documents may justify a narrow generic-knowledge update, not learner-performance evidence.

Assess answers and actual saved state separately. Record errors and model usage, with no benchmark comparison. This is bounded single-model behavior, not a population success rate or educational-efficacy test.
