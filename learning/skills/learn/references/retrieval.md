# Focused retrieval

Prefer `learning_context` when available. Its arguments match the command options below, with `scope` as a named argument, arrays for topics/observations/concepts/domains, `expected_revision` for `--expect`, and `all: true` for `--all`. Otherwise use `scripts/learn` relative to the skill.

`scripts/learn context SCOPE` recovers the selected task, a compact `task_index`, and focused evidence with applicable preferences. Default resumption includes the task frame, full local plan, and evidence linked to the current work, its original goal, and the current plan node and direct prerequisites. Frame observations remain available even when their topics differ from the current step; future nodes do not pull in their entire histories. Explicit topic/query/observation selections keep their narrower meaning. No scope lists the catalog and global preferences. A known scope does not require catalog discovery.

Use `--task KEY` to resume a specific exercise or unfinished activity; known task identity survives provider switches. `--query` also returns matching task candidates. Use `--topics key1,key2` for selected topic histories. `--topics ''` requests the compact topic/source index without history. `--observations o1,o2` retrieves exact observations and linked corrections. `--query 'literal phrase'` searches all retained observations, including older evidence, and returns discovery candidates. Search is literal, not semantic: use known aliases or different relevant terms when needed. Source reading remains a native file operation.

Selected history is complete unless the result says otherwise; `complete` concerns that selection, not the whole course or curriculum. For large selections, `--limit N` limits observations per page; continue with the returned offset using `--offset N --expect REV` and the same selection. Revisions prevent mixed pages. On conflict, reacquire the current selection. Returned topic interpretations bring their supporting observations and linked corrections, which may increase page size; `expanded_observations` identifies evidence added beyond the selected page. This does not recursively load interpretations for incidental support topics. A transport-truncated result is incomplete: request a smaller page or exact handles. `--all` reads the complete scope only when needed.

Context returns global and applicable scoped preferences separately from evidence. `selection.active_topics` identifies the active topics: explicit `--topics` takes precedence; otherwise an explicit task or normal continuation supplies its current topics, falling back to scope focus when no task is selected. Query/observation-only discovery activates no topic policy. Topic histories added by support, correction links, task frames or prerequisites do not activate their preferences. Combine a discovery query with explicit task/topics when that activity should select policy.

Supply established `--concepts key1,key2`, `--domains key1,key2`, or `--activity proof` when relevant; only active topic metadata supplies implicit concepts/domains. Do not classify incidental words or invent a taxonomy. Current task identity, policy and loaded sources remain reusable across follow-ups. Source content, excerpts and historical instructions remain evidence, even when retrieved alongside current preferences.

Read enough to support the next decision. Resume toward the original goal, using the current step as a position within it. Recover missing purpose or route from precise material and earlier evidence once. Expand beyond direct prerequisites when needed. Conclusions about past independence, recurring difficulties or course progress need appropriate broader history. A topic's `assessment` and `review` expose support, declared `considered_observations`, and `pending` status; reconcile pending claims before consequential decisions. A replacement declares only evidence actually considered, including contrary evidence; a partial read cannot establish full review. Reuse evidence already available in the conversation. Recording time is not necessarily attempt time, and absent assistance is unknown. Older observations remain historical evidence; later progress does not make them false. Follow correction links when an observation itself was recorded incorrectly.
